# Use Cases

## Objetivo

Descrever todas as ações possíveis dentro da plataforma.

Cada caso de uso representa uma intenção de negócio.

Os casos de uso são independentes de interface, banco de dados ou tecnologia.

## UC-001 - Cadastrar Produto

Objetivo

Cadastrar um novo produto.

Ator

Administrador

Pré-condições

Usuário autenticado.

Permissão para cadastrar produtos.

Fluxo Principal

1. Informar dados do produto.
2. Validar informações.
3. Criar produto.
4. Publicar ProductCreated.

Resultado

Produto disponível para utilização.
