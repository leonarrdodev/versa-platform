# Event Catalog

## Objetivo

Este documento descreve todos os eventos de domínio publicados pela plataforma.

Cada evento representa um fato ocorrido no negócio.

Os eventos são utilizados para integração entre contextos, automações, agentes de IA e geração da Memória Estratégica.
